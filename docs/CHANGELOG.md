## v0.2.6 — 2026-10-15（预发布）

新增双按钮 EXE 图形工具、二次确认和正常关闭应用流程。

完整组件覆盖 **87 个文件、8646 处文字替换**。本版翻译内容与 v0.2.5 相同，主要改进使用方式。

- 新增单文件 Windows 图形工具，只提供“汉化”和“还原”两个主操作。
- 执行前显示准备事项并二次确认，管理员身份同样需要确认。
- 确认后请求相关程序正常退出，保留未保存文档提示；程序仍未退出时停止，不强制结束进程。
- 保留免费来源提示、版本校验、备份及回滚；汉化差分内容与 v0.2.5 相同。
- 新增 GUI 安装模式和安全关闭模拟测试；26 项单元检查、24 项隔离安装检查通过。最终确认/自动关闭的真实端到端界面复核仍未完成。

## v0.2.5 — 2026-10-15（预发布）

补充 Excel 中的 ChemOffice 界面，强化免费来源提示。

完整组件覆盖 **87 个文件、8646 处文字替换**。

- 所有 CMD 窗口标题、启动及结束提示显示免费声明与 GitHub 地址；直接运行 PowerShell 和管理员窗口也显示来源。
- 本机安装完成，87 个目标文件校验通过；用户于 2026-10-15 反馈已完成 Excel 新增界面测试。
- 补充 ChemOffice Excel 功能区、菜单、提示及设置标签，新增 305 处界面替换。
- 保持功能区命令和回调、资源键、表结构及已有 86 个模块不变。
- 安装/还原涉及加载项时检查 Excel 是否退出；缺失该可选组件时跳过。
- 3 个通用按钮资源因空间不足保留原文；实际安装与界面验证状态另见 Excel 检查记录。


## v0.2.4 — 2026-10-14

补充 Chem3D 计算菜单、接口及设置窗口汉化。

完整组件覆盖 **86 个文件、8341 处文字替换**。

- 补充 6 个计算接口模块的菜单、窗口标题和设置控件，共新增 377 处计算界面替换。
- 保留计算关键字、资源名称、属性标识；缺少可选计算驱动时跳过该模块。
- 对主程序直接生成的“计算性质”菜单标签增加精确字节范围补丁，本机菜单显示已验证。
- 计算菜单采用与目标软件兼容的编码；安装/检查要求 Windows ANSI 代码页 936，不自动修改区域设置，还原英文不受此限制。
- 部分动态生成的 Buy Online or Learn More、About 项保留英文；第三方引擎计算未全面回归。

## v0.2.2 — 2026-10-14

补充 Chem3D 汉化，修正 Analysis 分析面板的中文布局。

完整组件覆盖 **80 个文件、7735 处文字替换**。

- 增加 Chem3D 菜单/对话框/字符串汉化，完整安装时共 80 个文件、7735 处替换。
- Chem3D 改为可选组件，普通安装/还原不删除注册表缓存；菜单缓存重置改为独立工具并先导出备份。
- 托管构建保留原生资源修改，再应用 139 处 UI 字符串调整。
- 菜单解析保留命令 ID、标志、头部偏移和尾部数据；拒绝截断模板。

- 修正 Analysis 分析面板的中文控件布局，宽度调整为 188×97 个对话框单位。
- 加宽分子式、精确质量、分子量、m/z 和元素分析选项，右移数值区。
- 标签使用英文冒号，保留选择项快捷键，加宽小数位数标签和数字输入区。
- 保留控件 ID、计算结果字段、控件类型和程序执行代码；分析面板更新限定在三份对应对话框资源。
- 差分包支持从 v0.2/v0.2.1 升级，并支持英文原版和已知 v0.1 状态。
- 发布附件改用英文文件名，避免 GitHub 自动规范化中文文件名。

## v0.2.1 — 2026-10-09

首次公开差分版：免费开源、跨电脑安装与安全还原。

完整组件覆盖 **78 个文件、5974 处文字替换**。

- 增加免费使用声明和 MIT 许可证，明确第三方权利范围。
- 从固定本机路径改为 Windows 标准目录、注册表查询和自定义路径输入。
- 增加显式程序/数据路径参数，提权时保留已选择的目录。
- 使用 COPY/LITERAL 差分发布，无完整 ChemDraw EXE/DLL 和预打包英文备份。
- 支持本机源文件重建、反向英文还原和已知 v0.1 状态升级。
- 安装前完成全部候选文件重建/校验，保留事务备份、全文件核验与失败回滚。
- 整理可审阅翻译源码、隔离测试及 GitHub 上传/发布说明。
- 中文翻译内容与 v0.2 相同，新增数量为零；不改变已知剩余英文项。
