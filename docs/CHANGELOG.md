# 更新记录

## v0.2.4 — 2026-10-14

- 补充 6 个计算接口模块的菜单、窗口标题和设置控件，共新增 377 处计算界面替换。
- 保留计算关键字、资源名称、属性标识；缺少可选计算驱动时跳过该模块。
- 对主程序直接生成的“计算性质”菜单标签增加精确字节范围补丁，本机菜单显示已验证。


## v0.2.3 — 2026-10-14

- 修复 Chem3D 的 MFC 状态/提示组合字符串未汉化及前导换行丢失。
- 补齐 106 组唯一提示，包含单双三键、平移旋转、MM2、表面和显示工具。
- 保留空状态段、分隔换行、快捷键与未相关的 PostScript 字符串。
- 完整组件仍为 80 个文件，累计 7953 处替换。

## v0.2.2 — 2026-10-14

- 增加 Chem3D 菜单/对话框/字符串汉化，完整安装时共 80 个文件、7735 处替换。
- Chem3D 改为可选组件，普通安装/还原不删除注册表缓存；菜单缓存重置改为独立工具并先导出备份。
- 托管构建保留原生资源修改，再应用 139 处 UI 字符串调整。
- 菜单解析保留命令 ID、标志、头部偏移和尾部数据；拒绝截断模板。

- 修正 Analysis 分析面板的中文控件布局，宽度调整为 188×97 个对话框单位。
- 加宽分子式、精确质量、分子量、m/z 和元素分析选项，右移数值区。
- 标签使用英文冒号，保留选择项快捷键，加宽小数位数标签和数字输入区。
- 保留控件 ID、计算结果字段、控件类型和程序执行代码；分析面板更新限定在三份对应对话框资源。
- 差分包支持从 v0.2/v0.2.1 升级，并支持英文原版和已知 v0.1 状态。
- 发布附件改用英文文件名，避免 GitHub 自动规范化中文文件名。

## v0.2.1 — 2026-10-09

- 增加免费使用声明和 MIT 许可证，明确第三方权利范围。
- 从固定本机路径改为 Windows 标准目录、注册表查询和自定义路径输入。
- 增加显式程序/数据路径参数，提权时保留已选择的目录。
- 使用 COPY/LITERAL 差分发布，无完整 ChemDraw EXE/DLL 和预打包英文备份。
- 支持本机源文件重建、反向英文还原和已知 v0.1 状态升级。
- 安装前完成全部候选文件重建/校验，保留事务备份、全文件核验与失败回滚。
- 整理可审阅翻译源码、隔离测试及 GitHub 上传/发布说明。
- 中文翻译内容与 v0.2 相同，新增数量为零；不改变已知剩余英文项。
