# 图形版 v0.2.6

下载 `ChemDraw-ZH-v0.2.6.exe` 后直接双击，主界面只有“汉化”和“还原”两个操作。仅支持 Windows 10/11 x64、ChemDraw 26.0.0.6141 x64；Chem3D 计算菜单仍要求 ANSI 代码页 936。

点击按钮后先显示准备事项：保存文档、核对版本、说明将关闭相关应用。二次确认默认选择“否”，选择“是”后才启动后端。管理员身份同样不跳过这一步。未提权时会出现系统 UAC 提示，由用户选择；以管理员身份启动时直接使用已有权限。

通过版本和文件检查后，请求 ChemDraw、Chem3D、化学性质窗口正常退出；仅在 Excel 加载项有待修改时请求 Excel 退出。不会强制杀死进程，不会代替用户处理未保存文档提示。20 秒后仍有相关进程时停止，用户保存并退出后可重试。已处于目标状态时不需要关闭应用。

工作文件、日志和备份保存在 `%LOCALAPPDATA%\ChemDrawZhPatch\runs`，无需自行选择位置。EXE 内仅包含项目原创启动器、安装脚本、许可证和公开差分数据，不包含原厂完整 EXE/DLL。

源码为 `gui/Launcher.cs`；构建命令：`python tools/build_gui.py`。使用 Windows 自带 .NET Framework C# 编译器，不下载依赖。EXE 与 CMD 使用同一安装器；翻译差分与 v0.2.5 相同。

验证范围：主窗口已实际查看，按钮与中文来源提示完整；曾观察到 Excel 正在运行时安全停止的反馈。最终二次确认及真实自动关闭流程尚未完成端到端界面复核。自动关闭使用模拟进程测试，覆盖正常退出、未保存阻止退出、后台进程不强杀、无 Excel 修改时不关闭 Excel。未在用户文档上测试强制关闭，也不存在强制关闭功能。
