# 开发与发布

用户使用 CMD 安装不需要 Python。开发源码使用 Windows 和 Python 3.10 或以上，差分工具无第三方 Python 依赖。

## 当前仓库内容

- `install.ps1`：通用路径识别、差分重建、校验、备份和回滚。
- `patches/*.cdp`、`manifest.json`：已生成的 v0.2.3 中文翻译差分与对应哈希，支持 26.0.0.6141 x64。
- `tools/delta.py`：COPY/LITERAL 差分格式生成与读取。
- `tools/export_deltas.py`：将开发者本地完整构建转换为公开差分。
- `tools/package_release.py`：按明确的文件清单打包，不包含 DLL、EXE、私有备份或日志。
- `localization/`：翻译词表、资源解析和汉化构建源码。原生资源构建依赖 Windows API。
- `tests/`：不依赖 ChemDraw 的差分测试，以及需要开发者本地软件文件的安装集成测试。

`patches` 是预生成发布材料。要验证或重新打包当前版本，不需要原厂文件：

```powershell
python -m unittest discover -s tests -p "test_*.py"
python tools/package_release.py
```

结果在 `dist/`；源码压缩包适合 GitHub 上传，通用差分压缩包适合 Releases 下载。`dist` 已被 Git 忽略。

## 修改翻译后重新构建

开发者必须在本地拥有受支持版本的软件。推荐在英文原版上进行反射字符串审核，避免从已汉化字面量中生成错误映射。

1. 从自己的安装捕获英文基线（只读取安装；也可根据已知反向差分恢复局部原文件）。

```powershell
python localization/capture_baseline.py --bin "C:\Program Files\RevvitySignalsSoftware\ChemDrawApplications_x64" --data "C:\ProgramData\RevvitySignalsSoftware\ChemDrawApplications\ChemDraw"
```

2. 审核/修改 `*_index.tsv` 中文译文。文件第一列是配套 `*_catalog.json` 或 `*_unique.json` 的索引，不能随意重排目录文件。品牌、数据绑定键、占位符和化学标识不能按普通文字全部替换。
3. 在**英文原版安装**上运行 `inspect_managed.ps1`，生成托管 UI 引用资料。此脚本会加载本地程序集并分析 IL，只对自己已安装且信任的程序集使用；输出仅用于本地构建，不上传仓库。

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File localization/inspect_managed.ps1 -BinPath "C:\Program Files\RevvitySignalsSoftware\ChemDrawApplications_x64"
python localization/build.py
python localization/build_managed.py
```

完整产物只在 `localization/package`，包括私有英文原文件和完整汉化文件。必须先运行 `build.py` 再运行 `build_managed.py`。不得直接上传这个目录。

4. 将本地构建导出为差分：

```powershell
python tools/export_deltas.py --package localization/package --output . --patch-version 0.2.3
```

如果本地构建清单带有 v0.1 legacy 哈希，需要同时提供本地旧项目目录 `--legacy-package "旧项目路径"`。新捕获流程默认不增加旧项目支持，现有公开清单则包含经验证的旧状态路线。

5. 在隔离目录运行安装集成测试，然后人工检查受影响窗口。安装集成测试需要本地完整包作为已知英文文件来源，不修改正式安装目录：

```powershell
python tests/verify_installer.py --local-package localization/package
```

修改翻译后要重新核实统计和窗口显示。保留英文原基线，禁止把运行时截图验证当成全部化学功能验证。修改脚本或资源格式后重新测试失败回滚。

## 差分格式

文件以 `CDZHD1\0` 开头，随后是 UInt64 小端输出长度。
操作 1：UInt64 原文件偏移、UInt64 长度，复制本机文件片段。
操作 2：UInt32 长度、字面量数据。
操作 0：结束。读取器检查输入边界、输出边界、总长度与尾随数据；安装器进一步验证完整目标 SHA-256。单文件输出限 256 MiB。

差分不是完整软件文件。它仍可能包含为重建必须使用的第三方字节片段；版权范围见 `NOTICE.md`。

升级支持：使用 `--previous-package "先前本地完整包路径"` 增加旧版到英文基线的转换路线。该目录只在本地使用，不加入公开包。

托管引用必须从英文原版提取，不能在已汉化软件上重新提取后直接混用英文词表。`build_managed.py` 会保留 `build.py` 已生成的原生资源；固定顺序为先原生、再托管、最后导出差分。
`--previous-deltas "旧差分包目录"` 可保留旧公开包中到相同英文基线的已校验恢复路线。
